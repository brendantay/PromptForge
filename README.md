# PromptForge
A zero-dependency, browser-only prompt generator inspired by the practical principles in DAIR.AI's Prompt Engineering Guide.

## Run
Open `index.html` directly, or deploy this folder to Netlify, GitHub Pages, Cloudflare Pages, etc.

## Design principles
- Explicit task/instruction
- Relevant context and input constraints
- Output-format control
- Optional examples / few-shot guidance
- Accuracy / hallucination guardrails
- Optional careful reasoning for complex tasks
- **No bullshit mode** for terse, direct responses without conversational filler

No backend, build process, API key, tracking, or dependencies.
